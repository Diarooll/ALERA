# Regras para agentes de IA

Nunca leia, abra, exiba, copie ou resuma arquivos `.env` ou `.env.*` deste repositório, em nenhuma pasta.

**Exceção:** o arquivo `.env.example` pode ser lido. Ele só tem os nomes das variáveis, sem valores de verdade, e é onde ficam listadas as variáveis que o projeto usa. Se precisar saber quais variáveis existem, leia o `.env.example`; se faltar alguma, pergunte ao responsável pelo projeto.
